* Infineon XDPE1x2xx Firmware Tools
This package provides below tools:
 1. xdpe1x2xx_dump: Used to dump firmware from XDPE1x2xx device.
 2. xdpe1x2xx_update: Used to update firmware to XDPE1x2xx device.
 3. test_xdpe1x2xx_dump: Used to verify firmware dump feature based on emulation.
 4. test_xdpe1x2xx_update: Used to verify firmware update process based on dummy SMBUS handler.
 5. libxdpe1x2xx.so: Library to provide XDPE1x2xx management features.

* WARNING
XDPE1x2xx use OTP (One Time Programmable) memory space to keep firmware. The operation of "invalidate all OTP section" means it will deactivate the running firmare. Shutdown the system without before activate new firmware might brick this component and the system will not be able to powered on.
XDPE1x2xx only provide totally 32K bytes of OTP space. It is not suggested update the firmware when it is required to do that.
The utility will report failed when there is no available for the new firmware.

* Usage

1. xdpe1x2xx_dump
* Naming Convention of dump file
    {ProductName}{ProductRevision}_{BusNumInDec}_{SlaveAddInDec}_Ver{TotalChecksum}.txt
* Example of file name
    XDPE19284C_5_114_Ver0xcdad5961.txt

a. Help
```
root@beoc:/tmp# LD_LIBRARY_PATH=${PWD} ./xdpe1x2xx_dump -h
XDPE1x2xx VR Firmware Dump Utility
Usage:
  -h: This helper

  * Example
      ./xdpe1x2xx_dump -b 0x5 -a 0x72 -p "/tmp"
  * Mandatory
      -b: Bus Number
      -a: Slave Address
  * Optional
      -p: Output path (default: /tmp)
```
